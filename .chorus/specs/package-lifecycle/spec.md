## Intent

按安装状态提供插件功能；需要启动初始化的包通过清单明确声明，在框架启动返回前完成初始化。框架只负责发现、契约、组合、加载和诊断，具体 Revit 业务仍由插件包实现。

## Requirements

以下为已确认需求，当前变更尚待提案批准和实现。

- [ ] 模块记录可选 `autoStart`，缺省或 false 不启动初始化，原按钮按需加载不变。
- [ ] `autoStart: true` 使用同条记录 `assembly` 中的 `startupType`，在 Revit 主线程、框架 `OnStartup` 返回前同步调用初始化。
- [ ] 按模块顺序及 ID 确定调用顺序，每个合格模块在一次 Revit 会话中最多尝试一次；刷新、安装更新、按钮执行不重试初始化。
- [ ] 单包失败记录可定位诊断并继续其他包；成功实例在框架关闭时逆序清理，清理失败继续其他包。
- [ ] 自启集合来自已安装且通过发现与兼容校验的模块，与 Ribbon 布局呈现无关。
- [ ] 删除模块 Enabled/Visible、功能 DefaultState、相关公开状态成员及消费链；旧隐藏/禁用值不再限制已安装功能，正常写回不再输出它们。
- [ ] 保留真实故障诊断、重复 ID/目标校验、来源启停、Revit 兼容过滤，以及分组、排序、布局和工作区执行边界。
- [ ] 提供插件开发迁移指南、相关旧机制核查结果和跨仓库重编译交接记录。
- [ ] 完成 C# 静态回归；Windows/Revit 2020 会话验证须独立记录，不能由构建成功替代。

## Non-goals

- 不引入新的插件启停或隐藏开关，不自动执行 Ribbon 功能。
- 不新增依赖调度、版本范围求值、后台 Revit API 调用、程序集热卸载或实机业务逻辑。
- 不因字段被称作 legacy 就删除仍工作的来源配置、命令路由或布局规则。
