# 插件包同步启动与状态清理需求

## 背景与确认

目前启动只发现清单，点击按钮才载入业务 DLL；旧状态字段仍能阻止模块注册、功能组合及执行。用户已确认：随框架加载要调用初始化入口，在框架 `OnStartup` 返回前完成；单包失败记录并继续，本次启动不重试。产品按安装/卸载提供功能，需清理旧启停/隐藏状态体系。第二轮确认旧隐藏/禁用项统一按安装状态生效，并要求核查其他旧机制、形成文档交给插件包开发 agent。

这是实现提案，尚未开发或发布。源码依据为 e957ead 及工作区既有改动；所有新增文件位于 `/home/yilan/plughub`，原成果目录保留。当前 AGENTS.md 中概括的启用/禁用能力由上述较新的用户要求收敛为安装/卸载语义，其余约束继续适用。

## 功能与验收

| 编号 | 要求 | 可观察结果 |
| --- | --- | --- |
| R1 | 清单模块记录新增可选 `autoStart` 和 `startupType` | 缺省/false 不调用入口；true 使用该记录 assembly 和 startupType；读取、配置复制、安装/更新、写回后值不丢失；Schema、样例、校验工具一致 |
| R2 | 同步初始化且独立于 Ribbon | 已安装、通过 Revit 兼容性和重复 ID 等发现校验的包，按 Order 后 ID 顺序，在 Revit 主线程、框架 OnStartup 返回前调用；布局未呈现的模块仍可自启；不扫描远程仓库缓存，不自动执行功能命令 |
| R3 | 会话内一次与失败隔离 | 每个合格模块本会话最多尝试一次；无 DLL/无类型/类型错误/构造异常/入口异常或返回非成功均有模块 ID、阶段和原因诊断；其他模块及框架继续，刷新和点击不重试 |
| R4 | 生命周期清理 | 成功实例按逆初始化顺序调用关闭入口；一项失败不阻断其他项；已进入初始化但失败的实例只作一次尽力清理，插件负责可重复安全的资源释放 |
| R5 | 清除旧状态体系 | 删除模块 Enabled/Visible、功能 DefaultState、预设状态覆盖、公开契约状态成员及运行时/Manager/Schema/测试消费链；旧配置中的隐藏/禁用值忽略，不阻止注册/组合/执行，正常保存不再输出 |
| R6 | 保留有效能力 | Revit 兼容过滤、重复 ID 检查、注册目标/工作区执行校验、故障诊断、来源/仓库 enabled、仓库 public/private、WPF Visibility、布局/分组/排序保持；不恢复另一套状态开关 |
| R7 | 迁移与交接 | 给出旧字段处理、所有已核查相关机制的保留/调整/限制及 9 个插件模块的源码影响；交给正确的插件包开发实例，先准备迁移，待新 Contracts 可用后重编译联调 |

## 兼容与错误行为

旧 JSON 通过现有反序列化器对未知字段的通用处理读入，不保留专门旧字段 DTO 或映射桥。旧清单和新清单均可发现；写入仅发生在用户正常保存/安装更新流程，不遍历改写磁盘所有配置。旧字段值失效会使先前隐藏/禁用的已安装功能恢复可用，这是用户选择的迁移规则。工作区布局规则仍可筛选功能，但不参与自启资格判断。

本次删除公开 Contracts 成员属于源码/二进制兼容变更：引用这些成员的包必须修改并用新 Contracts 重编译，不能宣称旧 DLL 无需处理。现有 9 个包均应删除状态赋值；默认仍不自启，不能因包名如 ProjectAutoSave 就自动设置 true。发布前需协调框架/包版本、安装顺序及回退材料。

自启失败不创造功能 Hidden/Disabled 状态，不自动卸载包；功能仍走正常注册及执行校验。安装/更新自启声明到正在运行的 Revit 后，下次启动才生效；刷新不尝试新入口。已启动包在会话中卸载/更新时保持原实例至框架关闭，提示重启以完成生命周期切换。

## 非功能与边界

复用现有影子复制及缓存清理，避免锁住源包 DLL；不增加新外部依赖。自启耗时会计入 Revit 启动耗时，记录逐包结果和耗时，不使用 Task.Run 或超时线程中断来调用 Revit API。挂死的插件无法通过异常捕获隔离，包作者必须保持入口短小。

不实现依赖调度、框架版本范围求值、热卸载或具体业务；不借清理删除 commandKey、有效本地来源、布局规则等有消费者的机制。

实现任务需覆盖配置往返、旧字段值组合、资格与顺序、布局独立、一次尝试、故障矩阵和逆序清理。必须运行 `dotnet run --project src/PlugHub.StaticValidation/PlugHub.StaticValidation.csproj` 以及相关 C# 测试；构建 Revit 适配器时只采用项目已有 Installed/NuGet 参考路径。
